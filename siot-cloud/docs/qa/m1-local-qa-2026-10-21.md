## 아직 못 한 것 (M1 완료 조건 중)

- **Pi 실기기**: 새 compose(digest 고정, 마운트 축소, production 모드)·`install.sh --mode`·service 변경을 Pi 에 반영하고 B7(3000/3001 분리), 인터넷 차단 재부팅, C3 ①②③(플러그 100회·같은 명령 10회·443 차단 60초 복귀) 측정. 현재 Pi `.env` 에는 `SIOT_MODE` 가 없어 재설치 시 production 으로 바뀜 → 계속 dev 로 쓰려면 `--mode=dev`.
- **Fly 배포**: flyctl 없음. `Dockerfile`·`fly.toml`·`docs/ops/*` 만 준비. 배포·secrets·Postgres(PITR)·업타임 모니터(C4)·복원 리허설은 사용자 계정으로.
- **A3 시연**(`tools/partner-sim/demo.ts`, Pi 실기기 GW + 시뮬 GW): 배포 후.
- **스파이크 S1~S4**: S4(커미셔닝 시간 분포, 현 Pi)는 사용자 물리 조작 필요, S1~S3 는 2번째 Pi 필요.
- **GHCR 이미지**: 첫 `agent-v*` 태그 푸시 시 CI 가 arm64 이미지를 만든다(미실행).
- PWA 카메라 QR 스캔은 실기기(HTTPS) 확인 전.

## 로컬 재현 절차

```bash
# DB·환경
createdb siot_dev
cp siot-cloud/.env.example siot-cloud/apps/api/.env   # DATABASE_URL, 비밀 3개, PORT=8090, APP_ORIGIN=http://localhost:8090
cd siot-cloud/apps/api && set -a && . ./.env && set +a && npm run db:migrate
npm run admin -- org:create --name "조직"
npm run admin -- user:create --email installer@test.local --name 기사 --role installer --org org_... --password '...'
npm run admin -- apikey:create --org org_... --mode test
# API (PWA 는 apps/web/dist 를 서빙하므로 먼저 npm -w apps/web run build)
siot-cloud/scripts/dev-api.sh
# 시뮬 에이전트
cd matter-gateway-poc/agent && MATTER_BACKEND=sim SIOT_MODE=production SIOT_RELAY_URL=ws://127.0.0.1:8090/gateway \
  SIOT_DATA_DIR=/tmp/gw1/data DATA_DIR=/tmp/gw1/data HEALTH_DIR=/tmp/gw1/health RULES_FILE=/tmp/gw1/data/rules.json \
  OTBR_REST_URL='' PORT=3100 LOCAL_ADMIN_PORT=3101 SIM_DOOR_TOGGLE_MS=20000 node src/index.js
# 로그의 gatewayId/pubKey 로 출고 등록 → 라벨 코드 출력
npm run admin -- gateway:provision --id gw_... --pubkey ... --org org_...
```
